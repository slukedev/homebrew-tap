# slukedev/tap

Homebrew formulae and casks for slukedev's tools.

## Claude Profile Hub

Run separate Claude Desktop profiles side by side, each with its own sign-in, chats and
connectors. [Source](https://github.com/slukedev/claude-profile-hub)

```bash
brew install slukedev/tap/claude-profile-hub
```

The formula is generated by the claude-profile-hub release workflow from
`packaging/homebrew/claude-profile-hub.rb.in` in that repository.

## Expressive Gmail

Gmail rebuilt in Material 3 Expressive, for Safari. [Source](https://github.com/slukedev/expressive-gmail)

```bash
brew install --cask slukedev/tap/expressive-gmail
```

The cask's source of truth is `packaging/homebrew/Casks/expressive-gmail.rb` in the app's repository; `npm run release:mac` fills in its version and checksum.
