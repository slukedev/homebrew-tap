# slukedev/tap

Homebrew casks for [Expressive Gmail](https://github.com/slukedev/expressive-gmail).

```bash
brew install --cask slukedev/tap/expressive-gmail
```

The cask's source of truth is `packaging/homebrew/Casks/expressive-gmail.rb` in the app's repository; `npm run release:mac` fills in its version and checksum.
